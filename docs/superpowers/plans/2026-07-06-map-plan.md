# Map Component Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a provider-agnostic `map` Stimulus controller (with `osm`/`google`/`baidu`/`naver` adapters registered through a public `Map.registerProvider`-style registry) plus a Rails `sp_map` helper with a block-based marker DSL, covering display, markers, click-to-coordinates, and a server-rendered fallback link.
**Architecture:** JS package (`stimulus-plumbers/`) owns the `map` controller and a small adapter registry that each provider module registers itself into at import time — mirrors `Formatter`/`Formatter.register` in `plumbers/formatter.js`. Rails package (`stimulus-plumbers-rails/`) owns `Components::Map` (HTML structure, values/data-attrs, marker `<template>` DSL, provider-specific fallback URL) and the `sp_map` helper that wraps it.
**Tech Stack:** Stimulus 2/3, Vitest + jsdom, Ruby/Rails (Minitest), Capybara + axe-core (Cuprite driver) for accessibility, Nokogiri for HTML assertions.

## Global Constraints

- Follow WCAG 2.1 Level AA (`ARIA.md`).
- Doc Update Rule (root `CLAUDE.md`): JS controller API → `stimulus-plumbers/docs/component/map.md` only. Rails helper options → `stimulus-plumbers-rails/docs/component/map.md` only, linking to the JS doc, never repeating it. New exported controller → add row to `stimulus-plumbers/README.md` Controllers table in the same commit as the export. New Rails helper → add row to `stimulus-plumbers-rails/README.md` Components table in the same commit as the helper.
- **Stimulus contract CI gate** (discovered in this repo, not stated in the design spec but binding on every task that touches `data-map-*` attributes): `stimulus-plumbers-rails/test/stimulus_plumbers/stimulus_contract_test.rb` diffs `stimulus-plumbers-rails/vendor/component/manifest.json` (generated from literal `"map-target"` / `"map-*-value"` string keys found in this gem's `lib/`, via `rake build:manifest`) against `stimulus-plumbers/dist/controllers.manifest.json` (generated from the JS controller's `static targets`/`static values`/dispatched event strings, via `npm run build`). Every Ruby-side `data: { "map-target": ... }` / `data: { "map-xxx-value": ... }` key MUST have a literal matching declaration in `map_controller.js` — no dynamically interpolated identifiers, or the regex-based scanner silently drops them. Task 13 regenerates both manifests and runs this test.
- No cross-doc duplication: ARIA/WCAG rules live only in `ARIA.md`; component docs link to it, never restate it.
- Match existing style exactly (`Formatter.register` shape, `Plumber::Base`/`merge_html_options` conventions, `template.capture(self, &block)` DSL pattern used by `Timeline`/`OrderedList`).
- **Naming deviation from the spec's pseudocode, decided in Task 1:** the spec writes `Map.registerProvider(...)`, but `Map` is a JS/Ruby built-in (`window.Map`) — literally exporting a class named `Map` from `stimulus-plumbers/src/plumbers/map.js` would shadow the global `Map` constructor for any code in that file (and confuse consumers importing both). The registry class is exported as `MapProviders` instead, with static methods `registerProvider(name, adapter)` and `resolveProvider(name)`. This is the only public export from the registry module; adapters (`osm`/`google`/`baidu`/`naver`) are internal-only — not exported from `src/index.js` — mirroring how `plumbers/formatter.js` exports only `Formatter`/`FORMATTER_TYPES` and never the individual `formatters/*.js` strategy modules. Apps that need a 5th provider only ever need `MapProviders.registerProvider`.

```js
// stimulus-plumbers/src/adapters/map/load_script.js
const scriptCache = new Map();

export function loadScript(cacheKey, src) {
  if (scriptCache.has(cacheKey)) return scriptCache.get(cacheKey);

  const promise = new Promise((resolve, reject) => {
    const script = document.createElement('script');
    script.src = src;
    script.async = true;
    script.onload = () => resolve();
    script.onerror = () => {
      scriptCache.delete(cacheKey);
      reject(new Error(`Failed to load script: ${src}`));
    };
    document.head.appendChild(script);
  });

  scriptCache.set(cacheKey, promise);
  return promise;
}

export function resetScriptCache() {
  scriptCache.clear();
}
```

```js
// stimulus-plumbers/src/adapters/map/osm.js
import { loadScript } from './load_script';

const LEAFLET_JS = 'https://unpkg.com/leaflet@1.9.4/dist/leaflet.js';
const LEAFLET_CSS = 'https://unpkg.com/leaflet@1.9.4/dist/leaflet.css';

function ensureLeafletCss() {
  if (document.querySelector(`link[href="${LEAFLET_CSS}"]`)) return;
  const link = document.createElement('link');
  link.rel = 'stylesheet';
  link.href = LEAFLET_CSS;
  document.head.appendChild(link);
}

export const osmAdapter = {
  load({ scriptUrl } = {}) {
    ensureLeafletCss();
    const src = scriptUrl || LEAFLET_JS;
    return loadScript(`osm:${src}`, src);
  },

  init(viewportEl, { center, zoom }) {
    const map = window.L.map(viewportEl).setView([center.lat, center.lng], zoom);
    window.L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
      attribution: '&copy; OpenStreetMap contributors',
    }).addTo(map);
    return map;
  },

  addMarker(instance, { lat, lng, popupContent }) {
    const marker = window.L.marker([lat, lng]).addTo(instance);
    if (popupContent) marker.bindPopup(popupContent);
    return marker;
  },

  onClick(instance, callback) {
    instance.on('click', (event) => callback({ lat: event.latlng.lat, lng: event.latlng.lng }));
  },

  destroy(instance) {
    instance.remove();
  },
};
```

```js
// stimulus-plumbers/src/adapters/map/google.js
import { loadScript } from './load_script';

function buildScriptUrl({ apiKey, scriptUrl }) {
  return scriptUrl || `https://maps.googleapis.com/maps/api/js?key=${apiKey}`;
}

export const googleAdapter = {
  load(options = {}) {
    const src = buildScriptUrl(options);
    return loadScript(`google:${src}`, src);
  },

  init(viewportEl, { center, zoom }) {
    return new window.google.maps.Map(viewportEl, { center, zoom });
  },

  addMarker(instance, { lat, lng, popupContent }) {
    const marker = new window.google.maps.Marker({ position: { lat, lng }, map: instance });
    if (popupContent) {
      const infoWindow = new window.google.maps.InfoWindow({ content: popupContent });
      marker.addListener('click', () => infoWindow.open({ anchor: marker, map: instance }));
    }
    return marker;
  },

  onClick(instance, callback) {
    instance.addListener('click', (event) => callback({ lat: event.latLng.lat(), lng: event.latLng.lng() }));
  },

  destroy(instance) {
    window.google.maps.event.clearInstanceListeners(instance);
  },
};
```

```js
// stimulus-plumbers/src/adapters/map/baidu.js
import { loadScript } from './load_script';

function buildScriptUrl({ apiKey, scriptUrl }) {
  return scriptUrl || `https://api.map.baidu.com/api?v=3.0&ak=${apiKey}`;
}

export const baiduAdapter = {
  load(options = {}) {
    const src = buildScriptUrl(options);
    return loadScript(`baidu:${src}`, src);
  },

  init(viewportEl, { center, zoom }) {
    const map = new window.BMap.Map(viewportEl);
    map.centerAndZoom(new window.BMap.Point(center.lng, center.lat), zoom);
    return map;
  },

  addMarker(instance, { lat, lng, popupContent }) {
    const point = new window.BMap.Point(lng, lat);
    const marker = new window.BMap.Marker(point);
    instance.addOverlay(marker);
    if (popupContent) {
      marker.addEventListener('click', () => instance.openInfoWindow(new window.BMap.InfoWindow(popupContent), point));
    }
    return marker;
  },
```

```js
// stimulus-plumbers/src/adapters/map/naver.js
import { loadScript } from './load_script';

function buildScriptUrl({ apiKey, scriptUrl }) {
  return scriptUrl || `https://oapi.map.naver.com/openapi/v3/maps.js?ncpClientId=${apiKey}`;
}

export const naverAdapter = {
  load(options = {}) {
    const src = buildScriptUrl(options);
    return loadScript(`naver:${src}`, src);
  },

  init(viewportEl, { center, zoom }) {
    return new window.naver.maps.Map(viewportEl, {
      center: new window.naver.maps.LatLng(center.lat, center.lng),
      zoom,
    });
  },

  addMarker(instance, { lat, lng, popupContent }) {
    const marker = new window.naver.maps.Marker({
      position: new window.naver.maps.LatLng(lat, lng),
      map: instance,
    });
    if (popupContent) {
      const infoWindow = new window.naver.maps.InfoWindow({ content: popupContent });
      window.naver.maps.Event.addListener(marker, 'click', () => infoWindow.open(instance, marker));
    }
    return marker;
  },

  onClick(instance, callback) {
    window.naver.maps.Event.addListener(instance, 'click', (event) =>
      callback({ lat: event.coord.y, lng: event.coord.x })
    );
  },

  destroy(instance) {
    window.naver.maps.Event.clearInstanceListeners(instance);
```

```js
import { Controller } from '@hotwired/stimulus';
import { MapProviders } from '../plumbers/map';

export default class extends Controller {
  static targets = ['viewport', 'marker', 'fallback'];
  static values = {
    provider: String,
    apiKey: { type: String, default: '' },
    scriptUrl: { type: String, default: '' },
    center: Object,
    zoom: Number,
  };

  async connect() {
    this.adapter = MapProviders.resolveProvider(this.providerValue);
    await this.adapter.load({ apiKey: this.apiKeyValue, scriptUrl: this.scriptUrlValue });
    this.mapInstance = this.adapter.init(this.viewportTarget, {

      zoom: this.zoomValue,
    });

    this.markerTargets.forEach((template) => {
      this.adapter.addMarker(this.mapInstance, {
        lat: parseFloat(template.dataset.lat),
        lng: parseFloat(template.dataset.lng),
        popupContent: template.innerHTML,
      });
    });

    if (this.hasFallbackTarget) this.fallbackTarget.hidden = true;
    this.dispatch('ready');
  }

  disconnect() {
    if (this.adapter && this.mapInstance) this.adapter.destroy(this.mapInstance);
    this.mapInstance = null;
    this.adapter = null;
  }
}
```

# Map

Provider-agnostic map display with markers, click-to-coordinates, and a server-rendered fallback link. Ships with `osm` (Leaflet, no key required), `google`, `baidu`, and `naver` adapters; apps can register a 5th via `MapProviders.registerProvider`.

## Stimulus Identifier

`map`

## Provider adapter contract

```js
import { MapProviders } from '@stimulus-plumbers/controllers';

MapProviders.registerProvider('my-provider', {
  load(options): Promise<void>,          // injects/loads the SDK script once; cached per provider+key/url
  init(viewportEl, { center, zoom }): instance,
  addMarker(instance, { lat, lng, popupContent }): markerHandle,
  onClick(instance, callback): void,     // callback({ lat, lng })
  destroy(instance): void,
});
```

Built-in adapter names: `osm`, `google`, `baidu`, `naver`.

## Values

| Name | Type | Purpose |
| --- | --- | --- |
| `provider` | String | `"osm"` \| `"google"` \| `"baidu"` \| `"naver"` \| any name registered via `MapProviders.registerProvider` |
| `apiKey` | String | Passed to the adapter's `load()`; unused by `osm` |
| `scriptUrl` | String | Overrides the adapter's default SDK URL — supports a server-side proxy that appends the key and forwards the request, so no key is ever client-visible |
| `center` | Object `{lat, lng}` | Initial center |
| `zoom` | Number | Initial zoom level |

## Targets

| Name | Element | Purpose |
| --- | --- | --- |
| `viewport` | `<div>` | Where the provider's SDK mounts its canvas/DOM |
| `marker` | `<template data-lat data-lng>` | One per marker; `innerHTML` is arbitrary popup content, read at connect and passed to `addMarker` |
| `fallback` | `<a href="...">` | Always server-rendered; hidden once the controller initializes successfully |

## Dispatches

| Event | Detail | When |
| --- | --- | --- |
| `map:ready` | — | After load/init/markers/click-wiring all succeed |
| `map:clicked` | `{ lat, lng }` | The adapter's `onClick` callback fires |
| `map:load-failed` | `{ error }` | `load()`/`init()`/marker parsing throws — `fallback` stays visible; no automatic retry |

## Known limitation

Third-party map SDKs — Google/Baidu/Naver's canvas-rendered widgets especially — have historically poor built-in accessibility; keyboard nav and screen reader support inside the widget is largely outside this library's control. The `fallback` link is the accessible escape hatch.

```ruby
# frozen_string_literal: true

module StimulusPlumbers
  module Components
    class Map < Plumber::Base
      FALLBACK_URL_BUILDERS = {
        osm: lambda { |center, zoom|
          "https://www.openstreetmap.org/?mlat=#{center[:lat]}&mlon=#{center[:lng]}#map=#{zoom}/#{center[:lat]}/#{center[:lng]}"
        },
        google: ->(center, _zoom) { "https://www.google.com/maps?q=#{center[:lat]},#{center[:lng]}" },
        baidu:  ->(center, _zoom) { "https://api.map.baidu.com/marker?location=#{center[:lat]},#{center[:lng]}&output=html" },
        naver:  ->(center, zoom) { "https://map.naver.com/v5/?c=#{center[:lng]},#{center[:lat]},#{zoom},0,0,0,dh" }
      }.freeze

      def render(provider: :osm, center:, zoom: 12, api_key: nil, script_url: nil, height: "400px", **kwargs, &block)
        stimulus = {
          data: {
            controller:             "map",
            "map-provider-value":   provider,
            "map-api-key-value":    api_key,
            "map-script-url-value": script_url,
            "map-center-value":     center.to_json,
            "map-zoom-value":       zoom
          }.compact
        }
        html_options = merge_html_options(theme.resolve(:map), kwargs, stimulus)
        markers_html = block ? template.capture(self, &block) : nil

        template.content_tag(:div, **html_options) do
          template.safe_join([render_viewport(height), markers_html, render_fallback(provider, center, zoom)].compact)
        end
      end

      private

      def render_viewport(height)
        template.content_tag(:div, nil, **merge_html_options(
          theme.resolve(:map_viewport),
          { style: "height: #{height}", data: { "map-target": "viewport" } }
        ))
      end

      def render_fallback(provider, center, zoom)
        builder = FALLBACK_URL_BUILDERS.fetch(provider.to_sym, FALLBACK_URL_BUILDERS[:osm])
        html_options = merge_html_options(
          theme.resolve(:map_fallback_link),
          { href: builder.call(center, zoom), data: { "map-target": "fallback" } }
        )
        template.content_tag(:a, "View on map", **html_options)
      end
    end
  end
end
```

## Helper
